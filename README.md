# 🖼️ Multi Stage Comparator

A scroll driven, **multi-stage image comparator** built with **HTML, CSS and JavaScript**. Layered images animate and reveal progressively as you scroll, with automatic z-index, clip-path and percentage tracking.

---

## 🚀 Features

- 🔄 **Scroll-driven animations** : Images transition smoothly based on scroll position.
- 🏗️ **Automatic layering** : `sibling-index()` and `sibling-count()` calculate z-index and clip-path dynamically.  
- 🎨 **Dynamic overlays** : Stage labels and text appear progressively with scroll.  
- 📊 **Percentage tracking** : Scroll progress is calculated and displayed with CSS `@property` and JS.  
- 📱 **Responsive design** : Works on mobile and desktop, maintaining aspect ratios.  
- ⚡ **Lightweight & fast** : Pure CSS and JavaScript and no external libraries required.  
- 🧩 **Easy customization** : Add/remove stages, and CSS recalculates automatically.  
- 🌐 **Modern browser support** : Best viewed in latest Chrome.
